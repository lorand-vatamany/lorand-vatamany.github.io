Privacy policy: yt-viewer

Last updated: 5 October 2026

yt-viewer is a personal command-line tool used by a single person, its owner, to manage their own YouTube channel. It runs only on the owner's computer.

What data it accesses

With the owner's permission, granted through Google's sign-in screen, yt-viewer uses the YouTube Data API and YouTube Analytics API to:

  • upload videos that the owner produced to the owner's channel;
  • read the owner's channel and video details and statistics (titles, views, likes, comments);
  • read the owner's channel analytics reports (for example, watch time and audience retention).

How the data is used and stored

  • The data is used only to upload the owner's videos and to show the owner how their videos perform.
  • The Google sign-in token and any statistics are stored only on the owner's own computer.
  • No data is sold, shared with third parties, or used for advertising.
  • No data about other YouTube users or viewers is collected beyond the aggregate statistics YouTube provides to the channel owner.

yt-viewer's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Use of YouTube data is also subject to the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also removes it.
