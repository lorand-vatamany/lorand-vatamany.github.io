yt-viewer

A personal, single-user tool by Lorand Vatamany.

yt-viewer is a small command-line tool that runs only on its owner's own computer. It helps the owner run their YouTube channel Fund Your Freedom: it uploads videos the owner has produced and reads the channel's own statistics (views, likes, comments, watch time) so the owner can see how videos perform.

It is not a public service. It is not offered to other users, and it accesses no YouTube account other than the owner's own channel.
